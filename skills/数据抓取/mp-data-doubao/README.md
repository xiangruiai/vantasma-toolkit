# mp-data-doubao

> 在豆包工作里装一个 Skill，一句话抓你公众号全部文章的阅读数据。
> 不用写代码，不用装 Python，一句提示词搞定。

把公众号后台的发表记录数据（阅读、分享、在看、点赞、留言）自动抓取、清洗、排序，写入飞书多维表格，再自动生成月度趋势图、阅读 TOP10、互动率 TOP10 和赞阅比 TOP10 四张图表，外加一个可交互的飞书数据看板。

---

## ✦ 为什么做这个

公众号数据复盘有一个共同的问题：**数据存在了，但整理太费时间**。

每次发完文章想看数据，得登录公众号后台，一篇一篇点开看阅读、点分享、点在看，抄到表格里再手动算互动率。发文多了以后，光是抄数据就要半小时。

豆包工作的云浏览器 + 飞书多维表格给了另一条路：

> 数据让 Agent 抓。<br>
> 表格让多维表格存。<br>
> 洞察让图表讲。

这个 skill 把公众号后台的发表记录抓取方案适配到了豆包工作的云浏览器环境。你只需要一句话，它就会打开云浏览器、登录公众号后台、逐页翻完发表记录、筛掉已删除的文章，把 102 篇有效文章的数据自动整理好。

跑出来的样子——飞书多维表格自动生成的数据看板：

- 总阅读 175,472 / 发文 102 篇 / 平均阅读 1,720 / 总点赞 4,581
- 月度总阅读趋势折线图
- 互动率月度趋势 + 赞阅比月度趋势并列
- 月度发文篇数柱状图
- 阅读量 TOP10 排行榜（带奖牌图标）

---

## ✦ 能拿到什么数据

| 数据项 | 说明 |
|---|---|
| 阅读数 | 每篇文章的阅读次数 |
| 分享数 | 每篇文章的分享次数 |
| 在看数 | 每篇文章的在看次数 |
| 点赞数 | 每篇文章的点赞次数 |
| 留言数 | 每篇文章的留言条数 |
| 发布状态 | 已发表 / 已删除 / 未通知 / 置顶 |
| 总阅读 | 全部有效文章的阅读总和 |

## ✦ 安装

### 前置条件

- 一个豆包工作账号（标准套餐即可）
- 你的公众号后台在浏览器里是登录状态（或者你有一台能扫微信二维码的设备）

### 三步安装

第一步，打开豆包工作，进入技能页面，点新建。

第二步，把 GitHub 仓库里的 SKILL.md 内容粘贴进去，保存。

第三步，回到对话页面，选中这个技能，说一句"抓一下我公众号全部文章的阅读数据"，它就会自动打开云浏览器，抓完所有文章数据，出图表，写进多维表格。

不需要装 Python，不需要配环境，不需要写一行代码。

---

## ✦ 边界

- 别人的公众号，精确的阅读数据拿不到。这个能力腾讯只开放给微信客户端自己。
- 数据有一天延迟，当天发的文章，第二天才出数。
- 后台的接口只保留 30 天窗口，超过就查不回了。
