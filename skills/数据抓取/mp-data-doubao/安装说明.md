# mp-data · 豆包工作适配版

把「公众号数据」技能移植到豆包工作（Doubao Work）上，用它的内置云浏览器抓公众号发表记录数据。

## 与本机版的差异

| | 本机版（macOS） | 豆包工作版 |
|---|---|---|
| 浏览器 | 本机 Playwright/Chrome | 豆包内置云浏览器 |
| 登录态 | `~/.mp-data-browser` 持久保存 | 云端是否保留不确定，可能每次任务要扫码 |
| 抓取方式 | Python 逐页 + DOM 提取脚本 | 浏览器操作剧本（SKILL.md 指令），支持 JS 时优先跑提取脚本 |
| 输出 | `/tmp/mp_all_publish_data.json` + HTML 报告 | 豆包直接输出表格文件与分析结论 |

## 安装到豆包工作

1. 打开豆包工作 → 技能/自定义技能 → 创建新技能。
2. 把本目录 `SKILL.md` 的内容粘贴进去（或上传该文件，以豆包当时支持的导入方式为准）。
3. 建议触发词保持「公众号数据」。

## 使用与注意

- 运行时豆包会打开云浏览器进 mp.weixin.qq.com，**首次需要你本人微信扫码**；扫码页出现时豆包会停下来等你。
- 登录公众号后台走的是豆包云端的出口 IP，首次可能触发微信安全验证，扫码通过即可；如果频繁要求验证，说明该出口 IP 被风控，此路就不适合常态化使用。
- 授权范围只有「读取发表记录」：技能里已写死不碰任何设置/群发/删除操作。
- 豆包云端浏览器是否在任务间保留登录态，需要实测：能保留就只需扫一次码；不能保留则每次任务扫一次。
