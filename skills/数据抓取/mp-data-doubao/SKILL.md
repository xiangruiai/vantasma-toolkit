# 公众号数据抓取技能（云浏览器版）

两类任务，先确认用户要哪个：
- **任务 A（自己的号）**：登录用户自己的公众号后台，抓「发表记录」全量数据。
- **任务 B（其他博主）**：通过后台的「超链接搜索」拿到目标公众号的文章列表，再逐篇打开文章页抓公开互动数据（阅读/在看/点赞）。

## 通用纪律（两个任务都遵守）

1. 只使用用户授权的登录态；**不修改任何设置、不群发、不删除任何内容**。
2. 翻页/逐篇访问间隔 3~5 秒，动作放慢。
3. 遇到验证码、安全提示或"操作频繁"：立即停下，把页面情况告诉用户，等用户在浏览器画面里处理后说"继续"。
4. 需要扫码登录时：停在二维码页面，明确请用户用微信扫码，最长等 3 分钟。

## 任务 A：抓自己号的发表记录全量数据

### A1. 登录后台

打开 `https://mp.weixin.qq.com/`，地址栏出现 `token=数字` 即已登录（记住 token）；出现二维码则请用户扫码。

### A2. 逐页抓发表记录

依次打开（begin 每次 +10，直到某页没有文章卡片）：

```
https://mp.weixin.qq.com/cgi-bin/appmsgpublish?sub=list&begin={N}&count=10&token={token}&lang=zh_CN
```

每张文章卡片提取：标题、日期、阅读数、分享数、在看/好看数、点赞数。

支持执行脚本时优先在控制台跑：

```javascript
var out = [];
document.querySelectorAll('.weui-desktop-block').forEach(function(b) {
  var card = b.querySelector('.weui-desktop-mass-appmsg');
  if (!card) return;
  var dateEl = b.querySelector('[class*=date], [class*=time]');
  var title = card.querySelector('.weui-desktop-mass-appmsg__title');
  var num = function(sel) {
    var el = card.querySelector(sel);
    return el ? parseInt(el.innerText.trim().replace(/,/g, '')) || 0 : 0;
  };
  out.push({
    title: title ? title.innerText.trim() : '',
    date: dateEl ? dateEl.innerText.trim() : '',
    read: num('.appmsg-view'),
    share: num('.appmsg-share'),
    watch: num('.appmsg-haokan'),
    like: num('.appmsg-like')
  });
});
JSON.stringify(out);
```

### A3. 输出

全量数据表（日期 | 标题 | 阅读 | 分享 | 在看 | 点赞）+ 简要分析（总篇数、总阅读、均值、阅读 TOP3、互动率 TOP3）。

## 任务 B：抓其他博主的文章列表 + 公开数据

> 原理：登录用户自己的后台，用图文编辑器里自带的「超链接 → 选择公众号文章」搜索功能翻目标号的文章列表（这是后台正规功能）；列表只含标题/日期/链接，互动数据再逐篇到文章页读取页面公开数字。不要绕过界面直接调接口——裸接口会被限频（错误 200013）。

### B1. 登录自己的后台

同 A1。

### B2. 进入图文编辑器打开超链接面板

1. 打开 `https://mp.weixin.qq.com/`，进入「内容与互动 → 草稿箱 → 写新图文」（新建一篇图文进入编辑器；这篇草稿只是工具，结束后可删除，不发布）。
2. 在编辑器正文里随便输入一个字并选中它，点工具栏的「超链接」图标。
3. 弹窗里选择「公众号文章」选项卡，会出现一个搜索框。

### B3. 搜索目标公众号并翻其文章列表

1. 在搜索框输入目标公众号名称（如"新榜"），会列出匹配的公众号，选择正确的那个。
2. 页面会展示该公众号的文章列表（标题 + 日期）。**逐页往下翻**（点"更多"/滚动加载），每页提取：标题、日期、文章链接。
3. 累积到用户要的数量（或翻到底），把链接清单保存下来。

### B4. 逐篇抓权威互动数据

⚠️ 重要：微信文章的阅读/在看/点赞数字**只在微信客户端环境下加载**。普通浏览器打开文章只有正文，没有数字。要拿到权威数字，文章链接必须带 `key=` 参数（微信客户端复制链接时自动附带，约 1~2 小时过期）。

操作：
1. 请用户在手机/电脑微信里打开目标博主的文章，点右上角「复制链接」（复制出来的是带 key 的链接），把链接发给你。
2. 逐个打开带 key 的链接（间隔 3~5 秒），从页面底部读取：**阅读数**（可能显示"10万+"，原样记录）、**在看**、**点赞**。
3. 汇入清单：`日期 | 标题 | 阅读 | 在看 | 点赞 | 链接`。
4. 如果用户给的链接没有 key 参数（普通分享链接）：打开后没有数字，如实告知用户"请从微信里复制链接"，不要编造数字。

### B5. 输出

- 目标公众号的全量文章清单表。
- 有互动数据的文章汇总表 + 阅读 TOP10、互动率 TOP10。
- 说明一句口径：这些是文章页公开数字（次数口径、10万+ 封顶），与博主自己的后台精确数据不同。

### 异常处理

- 超链接面板里搜索不到目标号：换个关键词（号的全名/简称）再试；仍搜不到就告诉用户该号可能改名或被搜索屏蔽。
- 列表翻页时出现"操作频繁"：停下等 60 秒再继续；连续两次失败就交付已抓到的部分。
- 编辑器报错或功能不可用：截图告知用户当前页面状态，等用户指示。

---

## 交付口径（用户问起时回答）

- 任务 A 的数据 = 后台发表记录页显示的数字，与后台一致、无时间限制。
- 任务 B 的数据 = 微信客户端口径的公开数字（阅读次数、10万+ 封顶），和作者后台看到的是同一来源，属权威公开数据；但需要用户从微信里复制带 key 的链接才拿得到，key 约 1~2 小时过期。任何第三方平台宣称的"任意号阅读数据"都只是估算。
