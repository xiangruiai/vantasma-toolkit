写公众号最麻烦的部分，往往不是把文字写出来，而是让排版在编辑器里保持稳定。

## 为什么要做确定性排版

公众号编辑器会过滤一部分 HTML 和 CSS。浏览器里看起来正常的页面，粘贴后可能出现列表错位、加粗断行和图片丢失。

>> 排版不是把页面做得更花，而是让读者更顺畅地看见内容。

### 三层重点标记

全文最重要的结论使用 ==黄色高亮==，正文关键词使用 ++浅绿下划线++，品牌名或产品名使用 **绿色加粗**。

💡 一段内不要同时堆叠太多强调样式。

## 自动校验

生成 HTML 后，脚本会检查公众号不兼容的标签和样式。

```bash
python3 validate_wx_html.py /tmp/wx_preview.html
```

⚠️ ERROR 必须修复，WARNING 需要人工判断。

## 写在最后

一套可靠的排版系统，应该让内容生产者把注意力放回内容本身。
