# RED / GREEN 记录

## RED：未加载 Skill

测试日期：2026-08-27。

通用 Agent 能守住基础安全边界，包括拒绝扫描整个 Documents、拒绝自动批量修复、不同步等同备份。主要失败不是“会破坏文件”，而是审计方法不稳定：

- 容易以文件数、链接数、标签率和新鲜度替代真实工作验证。
- 没有稳定覆盖“用得上”和“接得住”。
- 没有统一证据卡、P0 到 P3 和完成标志。
- 虽然区分自动指标与人工判断，但没有要求每个发现同时保留两者。
- 容易继续给出量化总分，掩盖未检查项。

## GREEN：加载 Skill 后的必须行为

- 先固定小范围并列出 Available / Not observed / Provided。
- 固定覆盖找得到、读得懂、用得上、接得住、救得回、管得动。
- 未检查项保持灰色，不估算。
- 自动信号不能直接变成红色结论。
- 每个黄红发现必须包含证据卡、P0 到 P3、下一动作和完成标志。
- Audit 不修改。Improve 只处理一个已确认问题，修改前预览并确认，修改后同例复测且保留回滚。
