# Taskboard 直接创建并执行目标设计

## 目标

让祥瑞不离开当前项目看板，就能把一个想法变成可追踪任务，并选择立即让 Codex 按这个任务执行。

## 已验证的现有链路

- `TaskEditor` 已能创建真实议题并返回完整 `Task`。
- `App.tsx` 的 `openTaskInThread()` 已能携带项目目录、议题编号和 `manage-taskboard` Skill 打开 Codex。
- Codex 注入层支持 `autoSubmit`，可以在输入框准备完成后立即提交。

## 直接方案

- 项目列表顶部增加常驻“新建任务”按钮，任务始终创建在当前高亮项目中。
- 新建编辑器把标题表达为“目标”，描述用于要求、验收标准和必要背景。
- 提供“仅保存”和“交给 Codex 执行”两个动作。
- “仅保存”沿用原创建流程与撤回能力。
- “交给 Codex 执行”将任务放入待办、负责人设为 Codex Agent，再调用现有创建对话链路自动提交。
- 任务是唯一事实来源，Codex 通过 `manage-taskboard` 读取任务，不在启动消息里复制另一份目标。

## 边界

- 自动执行只在 Codex 内置任务面板可用。
- 本轮不新增第二套目标字段，不改变自动认领策略，也不伪造 Codex 已经开始工作的状态。
